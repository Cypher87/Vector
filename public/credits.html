Data sources and credits

Aircraft metadata

Vector can use the aircraft database distributed by wiedehopf/tar1090-db, or metadata supplied by the configured receiver. Database records may be incomplete or outdated.

Contains information from the Mictronics aircraft database, made available under the Open Data Commons Attribution License.

The tar1090-db compilation also uses ADS-B Exchange data and additional aircraft type descriptions. See the upstream update process and source terms. Dataset terms are separate from the application and icon licenses.

Aircraft icons

Original aircraft-family silhouettes drawn for Vector, included under Vector's GPL-3.0 license. The separate aircraft metadata dataset above remains unchanged.

Other sources

Receiver data is provided by readsb. Photos and routes use separate external providers; photo credits and map attribution are shown in the interface.
